How to Use PhishGuard

Check a link before you open it. Here’s how to get started.

01

Copy the link

Copy the full web address you want to check. Avoid opening a suspicious link just to copy it; use the link’s copy option instead.

02

Paste it on Home

Return to the PhishGuard Home page and paste the address into the URL field.

Go to the link checker →
03

Analyze and review

Select Analyze Now and read the result. If anything seems suspicious, don’t enter passwords or personal information.

A link check is one useful signal, but no automated tool can guarantee that every website is safe. When in doubt, go directly to the organization’s official website.
